Gomoku
===

Language: python3

### The project:
The goal of this project is to implement a Gomoku Narabe game bot (also called Wuzi Qi, Slope,
Darpion
or Five in a Row), focusing on the performance of its artificial intelligence.

## USAGE:

### Prerequisites
* python3
* make
```
make
./pbrain-gomoku-ai
```
